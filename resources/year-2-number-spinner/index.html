Number detective

Use the number the wheel lands on.

  1. What is 1 more?
  2. What is 1 less?
  3. Is it odd or even?
  4. Write the number in words.
  5. How many tens and ones?

Spin twice

Spin two numbers. Record them, then:

  1. Add the two numbers.
  2. Find the difference.
  3. Which number is greater?
  4. Put the numbers in ascending order.

Challenge

Spin a number and make as many different number sentences as you can that equal it.

Example for 12: 10 + 2 = 12, 6 + 6 = 12, 15 − 3 = 12.

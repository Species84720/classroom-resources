# Listen & Write Number Spinner – Year 2 Teacher Guide

## Learning intention
I can listen to, recognise and write numerals from 1 to 20.

## Success criteria
- I can identify a spoken number from 1 to 20.
- I can write the matching numeral correctly.
- I can check and correct my answer independently.

## Suggested lesson flow
1. Give each child a whiteboard and pen.
2. Press **Say a number**. The numeral stays hidden while the browser reads it aloud.
3. Children write the number they hear.
4. Use **Hear it again** if the class needs a repetition.
5. Ask children to hold up their boards, then press **Show answer**.
6. Discuss reversals or common formation errors and repeat.

## Differentiation
### Support
- Display a 1–20 number line nearby.
- Let children point to the number before writing it.
- Replay the number and say it together as a class.

### Core
- Keep the number line hidden and ask children to write independently.
- Ask children to say one more or one less after revealing the answer.

### Challenge
- Children write the number in words as well as digits.
- Ask for the number before, after, or a simple number sentence with the spoken number as its answer.

## Technical notes
The activity uses the browser's built-in speech synthesis and prefers an English (UK) voice when available. Audio begins after a teacher presses a button, as required by modern browsers. Chrome, Edge and Safari generally provide speech voices. Ensure the device volume is on.

The random selector covers every whole number from 1 to 20 and avoids choosing the same number twice in succession.
